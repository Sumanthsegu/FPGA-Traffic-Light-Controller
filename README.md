# Project Documentation

This directory contains supporting documentation and evidence for the FPGA Traffic Light Controller.

Recommended files to add when available:

- `simulation_waveform.png` — Vivado behavioral simulation waveform
- `hardware_test.jpg` — photograph of the design running on the Zynq-7000 board
- `synthesis_report.png` — Vivado synthesis result
- `implementation_report.png` — Vivado implementation result
- `rtl_schematic.png` — RTL schematic

No board-specific XDC file is included because the original constraint file is currently unavailable.
